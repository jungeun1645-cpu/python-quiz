# 🐍 Python Quiz Game (파이썬 퀴즈 게임)

이 프로젝트는 파이썬의 기초 문법과 객체 지향 프로그래밍(OOP)을 학습하기 위해 만든 간단한 터미널 기반 퀴즈 게임입니다.

## 🚀 주요 기능
- **객체 지향 설계**: `Quiz` 클래스를 활용하여 문제, 보기, 정답을 관리합니다.
- **사용자 입력 처리**: 사용자가 입력한 번호를 받아 정답 여부를 판별합니다.
- **실시간 피드백**: 정답일 경우 축하 메시지를, 오답일 경우 재도전 안내를 출력합니다.

## 🛠 사용 기술 및 환경
- **Language**: Python 3.15.2
- **IDE**: VSCode
- **Version Control**: Git / GitHub

## 📂 프로젝트 구조
- `main.py`: 퀴즈 클래스 정의 및 게임 실행 로직이 포함된 메인 파일
- `.gitignore`: 불필요한 파일이 Git에 올라가지 않도록 설정

## 📝 학습 기록
1. **Git 환경 설정**: 로컬 저장소 초기화 및 GitHub 원격 저장소 연결
2. **클래스(Class) 활용**: 속성과 메서드를 가진 클래스 구조 이해
3. **디버깅 경험**: `ModuleNotFoundError`를 해결하며 파이썬의 `import` 경로와 파일 구조 이해
4. **사용자 입력(input)**: 터미널을 통한 데이터 입력 및 조건문 처리
